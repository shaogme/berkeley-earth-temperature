# 全球温度历史演变 3D/2D 可视化系统 (Premium Edition)

这是一个基于 **WebGL/Three.js** 3D 渲染技术和 **WebAssembly (WASM)** 高性能数据读取引擎构建的高科技全球气温历史演变交互式可视化系统。项目可以直接在前端浏览器中高效解析高达数百兆的科学 NetCDF-4 (`.nc`) 气温网格数据集，并以极具未来科技感的视觉动效，直观展示 1850 年至今全球气候变暖的演变趋势。

---

## 🌟 核心功能特性

### 1. 双维度高精度渲染引擎
- **3D 科技地球 (3D Globe)**：使用 PerspectiveCamera（透视相机）构建，包含逼真的星空粒子背景、大气层边缘发光 (Atmosphere Glow) 效果以及平滑的自转效果。
- **2D 投影地图 (2D Map)**：使用 OrthographicCamera（正交相机）消除透视畸变，保证平面的比例精确度，支持平移和无级缩放。
- **视图无缝过渡**：切换 3D 与 2D 视图时支持精美的淡入淡出动画，视觉流畅自然。

### 2. 纯前端 WebAssembly 数据解析 (NetCDF-4)
- **零后端依赖**：借助 `h5wasm.js`（WebAssembly 编译的 HDF5 读写库），系统直接在浏览器内存中创建虚拟文件系统 (VFS)，秒级解析复杂的 `.nc` 格式科学网格数据，完全避免了后端预处理的耗时和限制。
- **渐进式加载**：支持在 **5° × 5° 网格** (约 17.6MB) 和 **1° × 1° 网格** (约 427MB) 数据集之间按需切换。

### 3. 绝对温度与温度距平双通道渲染
- **绝对温度模式 (Absolute Temperature)**：直接展现格点的实际物理温度，配色采用多色平滑渐变（深蓝 -> 浅绿 -> 黄色 -> 红色）。
- **温度距平模式 (Temperature Anomaly)**：以相对于历史气候态基准的偏差（偏高或偏低）来展示全球变暖，采用专业气象发散色带（`RdBu` 色系：深蓝代表负距平，白色/浅黄代表 0°C，深红代表正距平），极其明显地凸显了近几十年来全球变暖的趋势。

### 4. 智能化多点/多国对比分析 (Multi-point Marker Analytics)
- **地图交互打点**：左键单击陆地区域可在地图上精准添加悬浮高科技标点（P1, P2 等），右键点击标点附近可快速取消。标签随地球转动到背面时会自动淡出隐藏，极具细节质感。
- **多曲线时空对比**：支持同时选取多个标点，一键生成对比分析曲线。通过 ECharts 模态框以“按年平均”或“按月波动”的形式，直观比对不同经纬度位置的气温演变差异。

### 5. 双向时空联动时间轴 (Overview + Detail)
- **概览时间轴**：底部展示 1850-2025 年全球历史年均温折线图，蓝色代表冷年份，红色代表暖年份，直观呈现百年升温总趋势。
- **刷选联动 (Scrubbing)**：用户可在底部折线图上直接点击或滑动拖拽来刷选年份，主场景（3D 地球/2D 地图）会实时渲染对应年份月份的气温分布，实现“概览指引细节，细节联动概览”的完美交互。

## 🛠️ 技术栈

- **3D 引擎**：[Three.js (r128)](https://threejs.org/)
- **控制与渲染插件**：`OrbitControls.js`，`CSS2DRenderer.js` (用于生成悬浮的国家名称与标点标签)
- **数据解析引擎**：`h5wasm.js` (WebAssembly 移植的 HDF5 库)
- **可视化图表**：[Apache ECharts (5.x)](https://echarts.apache.org/)
- **网络与资源分发**：支持从本地 Rust 服务器极速读取或自动降级至 GitHub Releases 远程下载。

## 🚀 快速开始

### 步骤 1：准备数据源文件
为保证最佳的载入性能，建议在本地部署数据集。
1. 在项目根目录下创建文件夹 `data/Global_TAVG_Gridded/`，并将伯克利地球气温 NetCDF 文件下载并放置于此：
   - 低分辨率（极速载入）：`5deg.nc`（约 17.6MB）
   - 高分辨率（高清渲染）：`1deg.nc`（约 427MB）
2. 在项目根目录下创建文件夹 `data/countries-land/`，将需要的不同精度的国家边界 GeoJSON 文件放入（例如 `countries-land-1m.geo.json`）。

> **备用方案**：如果本地没有对应的 `.nc` 文件，系统将自动尝试从 GitHub Releases 远程数据源中流式下载（由于体积达 427MB，视网络情况可能需要较长时间）。

### 步骤 2：启动本地资源服务器
由于浏览器出于安全性考虑（CORS 与 WebAssembly 虚拟文件读取等限制），直接双击 `index.html` 无法正常读取大文件。你需要运行本地服务器：
1. **使用预编译程序**：双击运行根目录下的 `local_server.exe`。它会在本地 `http://localhost:8080`（或默认配置端口）启动一个高性能静态文件服务器。
2. **源码运行（需 Rust）**：
   ```bash
   cd local_server
   cargo run --release
   ```

### 步骤 3：在浏览器中访问
打开 Chrome、Edge 或 Safari 浏览器，访问控制台输出的地址（通常为 `http://127.0.0.1:8080`），即可开启全球温度 3D 可视化系统。

## 📊 数据源声明

- **气温数据集**：来源于 [Berkeley Earth](https://berkeleyearth.org/) 的 Gridded Land Temperature 数据集（1850年至今逐月均温及距平）。
- **国家边界数据集**：基于 [Natural Earth](https://www.naturalearthdata.com/) 陆地数据处理而成的多精度边界网格。

## 💡 使用小贴士

1. **首次加载**：建议在弹窗中选择 **Low-Res (5deg) 数据集** 和 **5km/10km 边界精度** 进行极速体验。如需极致细节，且本地网络状况良好，可挑战 **High-Res (1deg)** 数据集。
2. **多点标点操作**：
   - 左键点击陆地标记位置，再次左键可以增加多个标点（最多支持 7 个颜色循环）。
   - 右键点击已有标点可以将其快速清除，点击侧边控制中心的“清空标点”可一键清空。
   - 点击“分析曲线”可查看多点历史趋势的大图表对比。
